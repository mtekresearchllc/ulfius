# Security policy

MTEK Research maintains this continuation of Ulfius. Security fixes target the
latest release and the `master` branch. Older releases do not have a separate
security maintenance commitment; update to the latest release when a fix is
available.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mtekresearchllc/ulfius/security/advisories/new)
to report a suspected vulnerability privately to this repository's maintainers.
Private vulnerability reporting is enabled for this repository. Do not publish
exploit details in a public issue or pull request before coordinated disclosure.

Include the affected version, platform, build options, a minimal reproducer,
and the security impact you observed. Remove credentials and other sensitive
application data from logs and examples.

The maintainers will investigate reports and coordinate fixes and disclosure
with the reporter. This project does not promise a response time or provide a
commercial security support agreement.

Ordinary bugs and maintenance questions belong in the
[issue tracker](https://github.com/mtekresearchllc/ulfius/issues).
The archived upstream project is not responsible for this continuation's
security reports or maintenance.
